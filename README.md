# Madhav Vidya Bhavan

Static website for the Delhi publishing house Madhav Vidya Bhavan.

Open `index.html` in a browser, or from this folder run:

```
python -m http.server 8765
```

Then visit http://127.0.0.1:8765/

The catalogue follows the thirteen editions listed for the house. The site does not take orders or send email. The enquiry page prepares a note the visitor can copy.
